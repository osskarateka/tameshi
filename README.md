# iPad端末管理簿

学校のiPadの在庫、配布・貸出と返却、アカウント、故障・修理をまとめて管理するWebアプリです。

- 画面は **GitHub Pages** に置きます(`index.html`)
- データは **Googleスプレッドシート** に保存します(`apps-script/Code.gs`)
- 先生方は、ウェブアプリのURLと合言葉を入れて使います。生徒の氏名などのデータはスプレッドシートにだけ保存され、GitHubには残りません。

---

## はじめの設定(管理担当の先生が1回だけ)

### 1. スプレッドシートを用意する

1. Googleドライブで新しいスプレッドシートを作り、名前を「iPad端末管理簿」などにします。
2. メニューの **拡張機能 → Apps Script** を開きます。
3. はじめから入っているコードをすべて消して、このリポジトリの `apps-script/Code.gs` の中身を貼り付けて保存します。
4. スプレッドシートの画面に戻って再読み込みすると、メニューに **「iPad管理簿」** が出ます。
5. **iPad管理簿 → ① シートを準備する** を選びます。合言葉が自動で作られて表示されます。初回は許可を求められるので、自分のアカウントで許可してください。
   「このアプリはGoogleで確認されていません」と出たら、「詳細」→「(安全ではないページ)に移動」で進めます。自分で作ったスクリプトなので問題ありません。
6. 合言葉はあとから **② 合言葉を表示する** で確認、**③ 合言葉を変更する** で変更できます。

### 2. ウェブアプリとして公開する

1. Apps Scriptの画面右上の **デプロイ → 新しいデプロイ** を開きます。
2. 種類の選択で **ウェブアプリ** を選びます。
3. 次のように設定して **デプロイ** を押します。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. 表示された **ウェブアプリのURL**(`https://script.google.com/macros/s/…/exec`)を控えます。

「全員」にしても、合言葉を知らない人はデータを読み書きできません。

### 3. GitHub Pagesで画面を公開する

1. このリポジトリの **Settings → Pages** を開きます。
2. Source を **Deploy from a branch**、Branch を **main / (root)** にして保存します。
3. 数分で `https://<ユーザー名>.github.io/tameshi/` が開けるようになります。

### 4. 先生方に知らせる

先生方には、次の3つを伝えてください。

- アプリのURL
- ウェブアプリのURL
- 合言葉

次の形のリンクを送れば、ウェブアプリのURLが最初から入った状態で開きます。

```
https://<ユーザー名>.github.io/tameshi/?api=<ウェブアプリのURL>
```

開くと接続設定が出るので、合言葉と自分の名前を入れて「接続する」を押します。設定はそのブラウザに保存されるので、次からは入れ直す必要はありません。

## ふだんの使い方

| やりたいこと | 場所 |
|---|---|
| 端末を1台ずつ登録・編集する | 端末一覧 → 端末を登録 / 行をクリック |
| 生徒や先生に渡す | 配布・貸出と返却 → 配布・貸出する |
| 返ってきた端末を記録する | 配布・貸出と返却 → 返却を受け付ける |
| 返却期限を過ぎた端末を見る | 上の「返却期限切れ」の数字を押す |
| 壊れた端末を記録する | 故障・修理 → 故障・破損を登録する |
| Excelからまとめて登録する | 取り込み・書き出し |
| Excelに書き出す | 取り込み・書き出し → CSVで書き出す |

- 「配布」は1人1台で長く持たせるとき、「貸出」は一時的に渡すときに使います。貸出では返却予定日を入れられます。
- ほかの先生が記録した内容は、30秒ごとに自動で反映されます。すぐに見たいときは右上の「最新にする」を押します。
- スプレッドシートを開けば、データを直接見ることもできます。ただし「ID」の列は書き換えないでください。

## 注意

- アカウントの **パスワードは記録しないでください**。
- スプレッドシートの共有範囲は、iPad管理に関わる先生だけにしてください。
- `Code.gs` を書き換えたときは、**デプロイ → デプロイを管理 → 編集(鉛筆) → バージョン: 新バージョン** で更新してください。URLは変わりません。
